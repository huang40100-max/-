# SLOWDAY COFFEE

React + TypeScript + Vite 專案，已設定 GitHub Pages repository path `/1111/`。

## 本機測試

```bash
npm install
npm run dev
npm run build
```

## 部署至 GitHub Pages

1. 將 ZIP **解壓縮後資料夾內的全部檔案與隱藏 `.github` 資料夾**上傳至 `huang40100-max/1111` 的 `main` 分支根目錄。不要把整個外層資料夾當作子資料夾上傳。
2. GitHub Repository > Settings > Pages > Build and deployment > Source 設為 **GitHub Actions**。
3. 到 Actions 檢查工作流程 `Deploy SLOWDAY to GitHub Pages`，確認成功。
4. 開啟 https://huang40100-max.github.io/1111/。

此網站使用示意圖片和課堂展示表單，地址、聯絡資訊、真實訂位尚待正式串接。
